Runpolio AI — 추천 API 시각 검증 도구

배포 전 실제 /api/v1/courses/recommend 응답을 지도에서 눈으로 확인하는 QA 전용 페이지. 서버 코드를 수정하지 않는다.

사용법
  1. FastAPI 서버 실행: uvicorn main:app --host 0.0.0.0 --port 8000 (프로젝트 루트, .env 필요)
  2. 이 파일을 브라우저로 직접 열거나(더블클릭) 로컬 정적 서버로 연다 — FastAPI가 서빙하지 않는 독립 파일이다
  3. 아래 "API 주소"에 로컬(http://localhost:8000) 또는 배포된 공개 URL 입력
  4. 부산 5개 지점 중 하나 선택 → 테마 선택 → "추천 API 호출" 클릭
  5. 지도의 경로 색과 카드의 좌측 색 막대가 1:1로 대응한다. ▲ = 시작점, ■ = 종료점
엔드포인트는 자동으로 /api/v1/courses/recommend 를 붙인다
API가 실제로 허용하는 값은 이 5종뿐이다 (schemas.py Theme enum)
